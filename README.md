# chimera-core-melonds

A core for [Chimera](https://github.com/ToolAssisted-run/chimera), the
frontend for tool-assisted speedruns, for the **Nintendo DS**. It is built
on [melonDS](https://melonds.kuribo64.net/) 1.1.

## Status

In work, and not published. [docs/PLAN.md](docs/PLAN.md) says what is done
and what was measured.
